# Task 1 — Order Tracking

Standalone React + Vite + Tailwind implementation of a responsive mobile-first e-commerce order tracking screen. It includes normal, loading, and error states.

Use the compact Demo states switcher to inspect in-transit, delayed, delivered, delivered-but-not-received, and tracking-unavailable states. It is assessment-only preview tooling; in a real product, the selected state would come from admin-managed order data. The URL equivalents are `?scenario=in-transit`, `?scenario=delayed`, `?scenario=delivered`, `?scenario=delivered-not-received`, and `?scenario=unavailable`.

```bash
npm install
npm run dev
```

Build with `npm run build` and preview with `npm run preview`.
