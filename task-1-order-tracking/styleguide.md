# Style guide

- Primary action: indigo/purple `#5146e5`.
- Page background: soft neutral `#f5f7fb`.
- Surfaces: white with `slate-200` borders and subtle card shadows.
- Controls use 8px rounding, visible focus rings, and inline validation.
- Layout is mobile-first with a centered maximum width and generous spacing.
- Phase illustrations use transparent square assets with consistent 56px timeline sizing and larger current-state sizing.
- Illustration colors reuse the UI indigo, amber, mint, and neutral palette.
